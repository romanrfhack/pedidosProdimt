## Límites

- SQL y secretos reales se generan únicamente al instalar el paquete.
- El bootstrap aplica migraciones antes de comprobar administradores existentes; debe apuntar exclusivamente a la instancia aislada del piloto.
- Restaurar un backup requiere una operación explícita; rollback de imagen conserva el esquema y no equivale a rollback de base.
- El acceso inicial es local o por túnel SSH. Dominio/HTTPS públicos no configurados.
- No se implementan producción física, entrega, cobranza o interpretación automática de WhatsApp en este subincremento.
